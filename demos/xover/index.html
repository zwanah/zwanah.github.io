ABOUT THE DEMO
    A little context.
    A world to explore.
    XOver Demo translates multilingual questions into OverpassQL using cross-lingual example selection, candidate execution and conservative repair.
    Ask→Inspect→Explore
    The demo uses six examples and three candidate queries. Research experiments use eight candidates. Historical selections and generated queries can be reused; their sources are displayed in Research details.
    Results use the project’s OSM snapshot, not a live world feed. Valid empty results are not repaired.
    An independent research project using OpenStreetMap data. Not affiliated with the OpenStreetMap Foundation.
